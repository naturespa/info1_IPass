# 情報Ⅰ ITパスポート CBT — info1_IPass

`pycbt`の表紙と`info1_ddl_public`のCBT画面を参考にした、学校向けITパスポート学習サイトです。紺・クリーム・黄を使い、文字と操作の境界が読み取りやすい配色にしています。

## 収録内容

令和8・7・6・5・4・3年度、令和2年度秋期、令和元年度秋期、平成31年度春期、平成30・29・28年度の春期／秋期。**15回 × 100問 = 1,500問**です。問題と選択肢・図表はIPA公開問題PDFから切り出し、解答は公式正解を使用しています。分野は各回の公式問題冊子の区分に沿っています。

指定されたITパスポート試験ドットコムの独自解説や画像は転載せず、復習時に該当する解説ページへリンクしています。詳しくは[出典画面](sources.html)、取得先は[scripts/sources.json](scripts/sources.json)、原本のハッシュは[data/catalog.json](data/catalog.json)を参照してください。

## 利用方法

- 授業用：35問・40分。年度と3分野から出題範囲を選択。
- 年度別模擬試験：原本の順番で100問・120分。
- 分野別練習：10／20／35／50／100問、1〜180分。出題対象が少ない場合はエラーを表示。
- 受験番号4桁・氏名を入力 → 確認 → 操作説明 → 試験開始。
- 解答保存、見直し印、解答一覧、白黒反転、表示倍率、原本の参考資料に対応。
- 再開しても期限は延びません。時間切れで自動採点します。
- 終了後は分野別結果・正解・復習リンクを表示。**結果JSONをダウンロードして提出**してください。

保存はブラウザのlocalStorageです。同じ端末・ブラウザから再開してください。ブラウザデータ削除・シークレットモード終了で消えます。通信切断時も、既に読み込んだ問題で解答できますが、未読の画像や外部解説には接続が必要です。

## GitHub Pagesで公開

このリポジトリはビルド不要の静的サイトです。

1. GitHubの **Settings → Pages** を開く。
2. Sourceを **Deploy from a branch**、Branchを **main / (root)** にしてSave。
3. 公開先：`https://naturespa.github.io/info1_IPass/`

教員用画面は `admin.html` です。設定した初期値を含む受験リンクを生成できます。設定を強制する機能ではなく、生徒が表紙から変更できます。

静的公開では、成績や名簿をサーバに送信しません。教員が生徒の結果JSONをまとめて読み込み、公式正解で再採点し、分野別成績のCSVを出力します。A列=4桁番号、B列=氏名のCSV名簿（UTF-8／Shift JIS）と照合できます。読み込んだ情報は管理画面のメモリだけに保持され、ページを閉じると消えます。公開リポジトリへ成績・名簿を置かないでください。

## 学校LANで成績を自動収集

サーバPCにNode.js **22.13以降**を用意し、リポジトリをダウンロードしてください。npm依存パッケージはありません。

```bash
npm start
```

Windowsでは `local-server/start.bat` も利用できます。

- サーバPC：`http://localhost:3000/`
- 生徒端末：`http://サーバPCのIPアドレス:3000/`（学校LAN内）
- 教員：サーバPCで `http://localhost:3000/admin.html` →「学校サーバの結果を読み込む」
- 保存先：`local-server/storage/ipass.sqlite`（Git管理対象外）。停止後にフォルダをコピーしてバックアップ。

POSTされた結果をサーバ側で再採点してSQLiteに保存します。受験IDで重複を防ぎます。管理画面・結果取得APIはサーバPCのlocalhostだけに制限しています。端末間通信はHTTPのため、学校内の管理されたLAN向けです。インターネットへポートを直接公開しないでください。

## 運用上の範囲

学習・授業での練習用です。静的問題データには正解が含まれ、受験者情報・開始時刻の本人確認や改ざん防止はありません。成績を用いる正式試験には、別途認証・出題制御・監督が必要です。得点は各問を等しく扱う正答率で、本試験のIRT評価点・合否と異なります。

問題は原本画像です。OCRによる文字起こしは行わず、図表や選択肢を保持しています。スクリーンリーダーで全文を読み上げることには対応していません。

## 開発・検証

```bash
npm run check
npm test
npm start
```

データ再生成にはPythonの `pymupdf pillow numpy` が必要です。原本PDFを `{年度ID}_ip_qs.pdf`／`{年度ID}_ip_ans.pdf` の名称で用意してください。

```bash
python scripts/build_bank.py --pdf-dir /path/to/pdfs
```

`scripts/boundaries.json`は原本のページ番号（0始まり）と2倍描画時の問題開始位置です。既存の年度JSONがある場合は生成をスキップするため、再生成対象のJSONを削除してください。原本PDFはリポジトリに含めていません。
